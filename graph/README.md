Ориентированный граф, имитирующий компьютерную сеть.
Граф представлен списком смежности.
Вершины графа хранят в себе уникальное имя компьютера (строка) и номер порта, на котором запущен сетевой сервис (беззнаковое целое число).
Ребра графа хранят в себе перечень портов, по которым разрешена передача трафика.
Граф поддерживает следующие операции:
1) Обход графа (поиск компьютера, который находится максимально близко к заданному и доступен с учетом ограничений на передачу данных)
2) Поиск кратчайшего пути между двумя вершинами (алгоритм Беллмана-Форда)
3) Разбиение сети на автономно функционирующие подсети, в которых узлы связаны между собой без учета ограничений на передачу данных (т.е. на компоненты сильной связности)
4) Добавление новой вершины или ребра
5) Удаление вершины или ребра
6) Изменение данных в вершине или в ребре
7) Вывод графа в виде списков смежности
8) Графический вывод графа при помощи утилиты graphviz
