Алгоритмы и структуры данных на C/C++.
Реализованы: 
1) Алгоритм Кули-Тьюки вычисления быстрого преобразования Фурье для вычисления произведения двух многочленов
2) Хэш-таблица методом цепочек
3) Сортировки:
    - Пузырьком
    - Оптимизированная пузырьком
    - Расческой
    - Вставками
    - Выбором
    - Шейкерная
    - Быстрая сортировка Хоара
4) Деревья
   - бинарное дерево поиска с прошивкой
   - 2-3 дерево
5) Графовые алгоритмы
   - DFS и топологическая сортировка
   - BFS
   - алгоритм Беллмана-Форда
   - алгоритм Косарайю
