2-3 дерево. Ключ - беззнаковое целое число, значение - нуль-терминированная строка.
Узел дерева содержит два поля ключей, указатели на левое, среднее и правое поддеревья, указатель на информационное поле. указатель на родительский узел.
В дереве допускаются дублирующие ключи, они хранятся в одном узле дерева в виде списка информационных полей.
Дерево поддерживает следующие операции:
1) Добавление нового элемента
2) Удаление элемента
3) Обход дерева. Выводится содержимое дерева в обратном порядке следования ключей в заданной диапазоне.
4) Поиск элемента по ключу. Если таких элементов несколько, возвращаются все.
5) Поиск элемента с ключом, наиболее близким к заданному, но не совпадающим с ним.
6) Вывод дерева в консоль
7) Графический вывод дерева при помощи утилиты graphviz
8) Загрузка дерева из .txt файла
