Бинарное дерево поиска с прошивкой.
Ключ - нуль-терминированная строка, значение - нуль-терминированная строка.
Узел дерева содержит ключ, указатели на левое и правое поддеревья, указатель на следующий узел и указатель на информационное поле.
В дереве могут храниться записи с дублирующими ключами - они хранятся в одном узле в виде списка информаицонных полей.
Поддерживает следующие операции:
1) Добавление нового элемента
2) Удаление элемента. Если присутствует несколько элементов с таким ключом, то удаляется наиболее старый из них.
3) Обход дерева. Выводятся все элементы дерева, которые начинаются с заданной подстроки
4) Поиск элемента по ключу. Если таких элементов несколько, то возвращаются все.
5) Поиск элемента с ключом, который максимально отличается от заданного
6) Вывод дерева
7) Графический вывод дерева при помощи graphviz
8) Загрузка дерева из .txt файла
